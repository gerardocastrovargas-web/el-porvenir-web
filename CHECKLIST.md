- [ ] Desktop, tablet, and mobile manual QA
- [ ] Investor copy and financing terms approved by owner
- [ ] Parcel geometry reviewed by surveyor and uploaded as valid GeoJSON
- [ ] Actual-photo versus conceptual-render labels verified
- [ ] Current rights to photographs / map tiles / fonts verified
- [ ] Official dates and full appraisal scope reviewed
- [ ] Privacy notice and contact-consent language finalized
- [ ] Supabase database and anti-spam configured if online lead capture enabled
- [ ] Lead delivery/notification flow tested
- [ ] `noindex` deliberately lifted only after publication authorization
- [ ] Lighthouse, accessibility, and Core Web Vitals tested on Vercel
